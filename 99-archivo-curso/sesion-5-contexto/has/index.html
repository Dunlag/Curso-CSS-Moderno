:has() en CSS

La pseudo-clase :has() permite seleccionar un elemento si contiene otros elementos que cumplan una condición. Es como un “padre” que reacciona a lo que hay dentro.

¿Qué hace exactamente?

Con :has() puedes aplicar estilos a un elemento basándote en la presencia o el estado de sus hijos (por ejemplo, si hay un checkbox activado, si un input está en foco, o si existe un elemento específico).

Idea clave: seleccionas el contenedor mirando hacia adentro.

.card:has(input:checked) { /* estilos */ }

Ejemplo 1: El contenedor cambia si hay un checkbox activo

Marca el checkbox. El estilo se aplica al contenedor completo porque contiene un input activado.
